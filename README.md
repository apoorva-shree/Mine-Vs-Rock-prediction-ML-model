# Rock vs Mine Prediction using Machine Learning
This project predicts whether an object is a Rock or a Mine using Sonar data and Machine Learning techniques.The model is trained using Logistic Regression.

The dataset contains sonar signal readings.
- R → Rock
- M → Mine

  ## Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- Google Colab

  project Workflow:
1. Import libraries
2. Load dataset
3. Data preprocessing
4. Train-test split
5. Train Logistic Regression model
6. Evaluate accuracy
7. Make predictions

## Machine Learning Model : Logistic Regression

## Accuracy
- Training Accuracy: 85%
- Testing Accuracy: 83%

1. Clone the repository
2. Install dependencies
3. Run the notebook
